🎵 Singlish：一个 vibe coding 出来的「听歌背单词」应用

🤔 起因 背雅思单词这件事，最大的问题不是"记不住"，而是无聊。单词书里的例句读到第三遍，人就已经走神了。 但歌词不一样。一句你单曲循环过一百遍的歌词，里面的单词想忘都忘不掉。所以这个项目只有一个想法：让每个雅思单词都住在一首真实的流行歌里，点一下，就听到歌手把这个词唱出来。 它叫 Singlish。字面意思是 Sing + English，边唱边学英语。它还有一层意思：在新加坡，Singlish 指的是新加坡人说的那种英语，句尾带个 lah 的那种。一个名字两种读法，我觉得挺合适：学英语本来就不必一板一眼。 🎧 它长什么样 在线体验： https://singlish.study/ 源码： github.com/bigjeager/singlish （截图里除目标词以外的歌词做了模糊处理，出于版权考虑。实际页面上歌词是完整显示的。） 🎤 它能干什么 100 个雅思词，每个词最多 3 首歌：一共 200 段试听、104 位歌手，Coldplay、Adele、Billie Eilish、Bruno Mars……还有我点名要多放的 The Weeknd 和 Imagine Dragons； 一个词，多首歌：手机上左右滑动换个词，上下滑动换个歌，右侧竖排的小圆点告诉你这个词还有几首；电脑上用 ↑↓ 键或点圆点切换； 按考试筛选：搜索框旁边有 雅思 / 四级 / 六级 / 托福 的词典标签，搜索栏滚动时一直固定在顶部； 官方原声，没有广告：播放的是 Apple Music 的 30 秒官方试听，只截唱到这个词的那十几秒； 卡拉 OK 式歌词：当前行放大，粉到橙的渐变随歌声逐词扫过，唱到目标词时，黄色荧光笔"啪"地弹一下；同一段歌词里的其他考试词用粉色标出，上方直接显示音标和释义；点任意一行，就从那一行开始唱； 像音乐 App 一样用：桌面端点卡片就唱，手机端左右滑动，滑到哪张唱哪张；默认一首接一首连着播，还有随机和单曲循环； 单词卡本身：英式音标（点一下会朗读）、中英释义、雅思常用搭配、雅思分段标签，以及"歌里唱的是 amazing，它是 amaze 的形容词"这类词形说明； 氛围：整个页面的背景是当前歌曲封面的模糊光晕，换一首歌，页面就换一种颜色；正在播放的封面是一张转动的 CD； 分享海报：一键生成带二维码的单词海报，直接调用系统分享； 纯静态：一个 index.html 加一份数据文件，托管在 GitHub Pages，绑定了自己的域名 singlish.study，没有后端。 ...
