AIAgent 类概览#

run_agent.py 中的 AIAgent 类是 Hermes 的核心引擎，负责：

  • LLM API 调用
  • 工具调用循环
  • 消息历史管理
  • 预算和中断控制

该文件约 14,000 行代码，是整个框架的心脏。

关键设计点#

  1. IterationBudget: 线程安全的迭代计数器

    • 父 Agent 上限 max_iterations (默认 90)
    • 子 Agent 独立预算 delegation.max_iterations (默认 50)

  2. 中断机制: 支持用户中断长时间任务

  3. Grace Call: 在预算耗尽后允许最后一次响应

OpenAI 延迟加载#

为优化启动速度，OpenAI SDK 采用延迟加载：

1# run_agent.py 中的代理模式
2class _OpenAIProxy:
3    """模块级代理，首次调用时才导入 openai.OpenAI"""
4    
5    def __call__(self, *args, **kwargs):
6        return _load_openai_cls()(*args, **kwargs)
7
8OpenAI = _OpenAIProxy()  # 模块级导出

这避免了 ~240ms 的导入延迟。

状态安全写入#

为防止崩溃，使用 _SafeWriter 包装 stdout/stderr：

1class _SafeWriter:
2    """捕获 OSError/ValueError，防止管道断裂崩溃"""
3    
4    def write(self, data):
5        try:
6            return self._inner.write(data)
7        except (OSError, ValueError):
8            return len(data) if isinstance(data, str) else 0

这在 systemd/Docker/headless 环境中尤为重要。
