工具系统概述#

Hermes 的工具系统采用自注册模式，核心文件：

  • tools/registry.py - 工具注册中心
  • model_tools.py - 工具编排层
  • toolsets.py - 工具集定义
  • tools/*.py - 各工具实现

自注册机制#

每个工具文件在导入时自动注册：

 1# tools/terminal_tool.py
 2from tools.registry import registry
 3
 4registry.register(
 5    name="terminal",
 6    schema={
 7        "type": "function",
 8        "function": {
 9            "name": "terminal",
10            "description": "Execute shell commands",
11            "parameters": {...}
12        }
13    },
14    handler=terminal_handler,
15    toolset="terminal"
16)

Async-Sync 桥接#

工具 handler 可以是同步或异步函数。_run_async() 统一处理：

 1def _run_async(coro):
 2    """从同步上下文运行异步 coroutine"""
 3    
 4    # 1. 检查是否在 async 上下文中
 5    try:
 6        loop = asyncio.get_running_loop()
 7    except RuntimeError:
 8        loop = None
 9    
10    if loop and loop.is_running():
11        # 在 async 上下文 - 使用线程池
12        pool = ThreadPoolExecutor(max_workers=1)
13        future = pool.submit(lambda: asyncio.run(coro))
14        return future.result(timeout=300)
15    
16    # 同步上下文 - 使用持久 loop
17    tool_loop = _get_tool_loop()
18    return tool_loop.run_until_complete(coro)

这避免了 “Event loop is closed” 错误。

工具集解析#

 1def resolve_toolset(name: str) -> list:
 2    """解析工具集到工具名称列表"""
 3    toolset = TOOLSETS[name]
 4    tools = toolset["tools"]
 5    
 6    # 递归包含的工具集
 7    for included in toolset["includes"]:
 8        tools.extend(resolve_toolset(included))
 9    
10    return tools
