技能系统概述#

技能是 Hermes 的知识注入机制，允许为特定任务场景提供：

  • 专用指令
  • 工作流程
  • 参考文档
  • 脚本和模板

skills/
├── autonomous-ai-agents/
│   ├── claude-code/SKILL.md
│   ├── codex/SKILL.md
│   ├── hermes-agent/SKILL.md
│   └── ...
├── creative/
│   ├── ascii-art/SKILL.md
│   ├── pixel-art/SKILL.md
│   └── ...
├── mlops/

│   ├── systematic-debugging/SKILL.md

~/.hermes/skills/   # 用户自定义技能

SKILL.md 格式#

每个技能是一个目录，包含 SKILL.md 文件：

 1---
 2name: claude-code
 3description: Delegate coding to Claude Code CLI
 4category: autonomous-ai-agents
 5version: 1.0
 6---
 7
 8## 触发条件
 9当用户请求编写代码、创建 PR、或需要复杂编程任务时使用。
10
11## 工作流程
12
131. 确认任务范围
142. 运行 `claude --acp --stdio`
153. 监控输出并返回结果
16
17## 命令示例
18```bash
19claude --acp --stdio --model claude-opus-4-6
20```
21
22## 陷阱
23- 需要安装 Claude CLI
24- 需要 Anthropic API key
25
26## 参考文件
27- [API文档](references/api.md)
28- [脚本模板](scripts/run.sh)

Frontmatter 字段#

  • name: 技能名称
  • description: 简短描述
  • category: 类别目录
  • version: 版本号
  • requires: 依赖工具

技能加载机制#

启动时扫描#

 1# agent/skill_commands.py
 2def scan_skills_directory():
 3    """扫描 ~/.hermes/skills/ 和 skills/"""
 4    skills = []
 5    for path in [HERMES_SKILLS_DIR, REPO_SKILLS_DIR]:
 6        for category in os.listdir(path):
 7            for skill_name in os.listdir(f"{path}/{category}"):
 8                skill_file = f"{path}/{category}/{skill_name}/SKILL.md"
 9                if os.path.exists(skill_file):
10                    skills.append(skill_name)
11    return skills

注入方式#

技能内容作为 User Message 注入（而非 System Prompt），以保持 prompt caching：

1def build_skills_system_prompt(enabled_skills):
2    """构建技能提示"""
3    content = "## Skills (mandatory)\n"
4    for skill in enabled_skills:
5        skill_md = read_skill(skill)
6        content += f"\n### {skill}\n{skill_md}\n"
7    return content

技能工具#

用户可通过工具管理技能：

1# tools/skills_tool.py
2def skills_list(category=None) -> list:
3    """列出可用技能"""
4
5def skill_view(name, file_path=None) -> str:
6    """查看技能内容"""
7
8def skill_manage(action, name, content=None, ...):
9    """管理技能: create, patch, edit, delete"""

技能使用流程#

用户: "帮我用 Claude Code 写个 PR"
       ↓
Agent 匹配技能: claude-code
       ↓
skill_view("claude-code") 加载 SKILL.md
       ↓
注入到上下文
       ↓
Agent 按技能指引执行
       ↓
运行 claude --acp --stdio
       ↓
返回结果

技能扩展#

创建新技能#

1# 使用 skill_manage 工具
2skill_manage(
3    action="create",
4    name="my-custom-skill",
5    category="custom",
6    content="SKILL.md 内容..."
7)

或手动创建：

1mkdir ~/.hermes/skills/my-skill
2cat > ~/.hermes/skills/my-skill/SKILL.md << 'EOF'
3---
4name: my-skill
5description: My custom workflow
6---
7# 工作流程
8...
9EOF

Optional Skills#

一些较大的技能放在 optional-skills/，默认不激活：

  • email/ - Himalaya CLI 邮件工具
  • blockchain/ - 区块链相关
  • health/ - 健康追踪
  • security/ - 安全测试

需要手动启用：

1# config.yaml
2skills:
3  enabled:
4    - email
5    - blockchain
