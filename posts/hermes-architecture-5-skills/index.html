技能目录结构#

SKILL.md 格式#

每个技能是一个目录，包含 SKILL.md 文件：

 1---
 2name: claude-code
 3description: Delegate coding to Claude Code CLI
 4category: autonomous-ai-agents
 5version: 1.0
 6---
 7
 8## 触发条件
 9当用户请求编写代码、创建 PR、或需要复杂编程任务时使用。
10
11## 工作流程
12
131. 确认任务范围
142. 运行 `claude --acp --stdio`
153. 监控输出并返回结果
16
17## 命令示例
18```bash
19claude --acp --stdio --model claude-opus-4-6

注入方式#

技能内容作为 User Message 注入（而非 System Prompt），以保持 prompt caching：

1def build_skills_system_prompt(enabled_skills):
2    """构建技能提示"""
3    content = "## Skills (mandatory)\n"
4    for skill in enabled_skills:
5        skill_md = read_skill(skill)
6        content += f"\n### {skill}\n{skill_md}\n"
7    return content

技能扩展#

创建新技能#

1# 使用 skill_manage 工具
2skill_manage(
3    action="create",
4    name="my-custom-skill",
5    category="custom",
6    content="SKILL.md 内容..."
7)

或手动创建：

1mkdir ~/.hermes/skills/my-skill
2cat > ~/.hermes/skills/my-skill/SKILL.md << 'EOF'
3---
4name: my-skill
5description: My custom workflow
6---
7# 工作流程
8...
9EOF

添加辅助文件#

Optional Skills#

一些较大的技能放在 optional-skills/，默认不激活：

  • email/ - Himalaya CLI 邮件工具
  • blockchain/ - 区块链相关
  • health/ - 健康追踪
  • security/ - 安全测试

需要手动启用：

1# config.yaml
2skills:
3  enabled:
4    - email
5    - blockchain
