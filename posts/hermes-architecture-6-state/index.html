状态管理概述#

Hermes 的状态管理包含：

  • Session: 会话历史持久化
  • Memory: 跨会话记忆
  • Config: 用户配置

记忆最佳实践#

应该保存：

  • 用户偏好（语言、风格）
  • 环境信息（OS、工具）
  • 项目约定
  • 用户修正和反馈

不应该保存：

  • 任务进度（用 session_search）
  • 临时状态
  • 一次性信息

系列总结#

Hermes Agent 架构核心要点：

  1. 分层设计: CLI → Gateway → AIAgent → Tools
  2. 自注册工具: 模块导入时自动注册
  3. 工具集抽象: 按场景组合工具
  4. 多平台 Gateway: 统一适配器接口
  5. 技能注入: 知识作为上下文
  6. SQLite + FTS5: 持久化与搜索

本系列基于 Hermes Agent v0.12 源代码分析完成。
